## نطاق الدليل وأولوية القرارات

هذا سجل للعمل الذي أمكن إثباته من المحادثة الحالية، وتوثيق المستودع عند
`33bc660f4c840fb87da2351d9f17429a710c1086`، وملفات الإنتاج المتاحة، وسياق المحادثات السابقة المسترجع عند الحاجة.
ليس ادعاءً باسترجاع جميع محادثات الحساب أو جميع فيديوهات القناة. طلب بلا ملف تسليم مثبت يبقى **طلباً موثقاً**.

1. طلب المستخدم الحالي يحكم المهمة الحالية.
2. تعليق المستخدم الصريح الأحدث يحكم النقطة التي ناقشها، ضمن نطاقها.
3. مرجع هوية القناة المعتمد يحكم الفراغات؛ الأمثلة القديمة مراجع تاريخية.
4. رأي المساعد أو المراجع الداخلي يثبت فحصاً فنياً، ولا يحل محل اعتماد المستخدم.

## كيف نقرأ الأدلة

- **C — المحادثة الحالية:** اقتباس مباشر من المستخدم؛ قد لا يتوفر تاريخ مستقل لكل رسالة، فلا نخترع تاريخاً لها.
- **R — المستودع:** ملف موجود ومقروء عند المراجعة؛ الروابط إلى المرجع المعتمد في الأسفل.
- **H — محادثة سابقة مسترجعة:** يحتفظ السجل بالتاريخ المتاح، ويميز قول المستخدم عن ادعاء مساعد سابق.
- **P — ملفات الإنتاج والفحص:** تنفيذ تقني وتسليم؛ لا تعني مراجعة المنتج الأصلي سريرياً أو إجراء معاملات حقيقية.
