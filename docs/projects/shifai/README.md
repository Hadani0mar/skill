# شفائي — توثيق فيلم المستثمرين V1 وV2

أُنتجت النسختان وسُلّمتا في **17 نوفمبر 2026**؛ توثيق المستودع في **18 نوفمبر 2026**.
الجمهور: مستثمرون. الهدف: بيان مشكلة تشتت التاريخ الصحي في ليبيا، والقيمة التي يقدمها ملف رقمي موحد، وما يحتاجه المشروع للمرحلة التالية.
الطلب: سرد مهني قوي ومطابقة المشروع. شعار المنتج: «صحتك على بُعد مسحة واحدة».

## المصدر وحدود المطابقة

- المشروع: [rashaalobiedy8/shifai](https://github.com/rashaalobiedy8/shifai).
- المراجعة التي بُني عليها الفيلم: `51ede1e0ae526084354d0efee2f4548db325372c`؛ هذه مطابقة لهذه المراجعة، لا وعد بمطابقة أي تحديث لاحق.
- لقطات أصلية من تطبيق Streamlit الحقيقي بدقة 2×، مع الحفاظ على عناصره وخطوطه وتسمياته. الإطارات والشرح حولها عناصر تحريرية.
- شعار `assets/logo.jpg` الأصلي استُخدم دون تغيير رسمه. كل بيانات المريض المعروضة تجريبية.
- رمز QR يشير إلى نطاق الأمثلة المحجوز `shifai.example`؛ ليس رابط مريض فعلي أو دعوة تسجيل إنتاجية.
- المشروع لم يُنشر أو يُعدّل ضمن صناعة الفيلم. حزمة الفيلم لا تضم مستودع التطبيق نفسه.

## ما يحلّه وما يقدمه فعلياً

| النقطة | ما أثبته الكود وقت الإنتاج | الصياغة المناسبة في العرض |
|---|---|---|
| تشتت التاريخ الصحي | ملف تجريبي محلي يجمع الأمراض المزمنة والحساسية والزيارات | تنظيم تاريخ المريض في سجل واحد؛ لا ادعاء قياس فعلي لخفض الأخطاء |
| الوصول بالـQR | توجيه إلى عرض الطبيب عبر رابط المريض | وصول عبر المتصفح ومسح الرمز، دون تحميل تطبيق؛ متطلبات الاتصال والصلاحيات تعتمد على النشر |
| تفاعلات الأدوية | بحث في بيانات جدول/XLSX | أداة فحص ضمن النموذج؛ لا شهادة شمول أو اعتماد سريري |
| التنبؤ الدوائي | نموذج ML تجريبي يصدر تصنيفات دوائية | **نموذج تجريبي يحتاج تحققاً سريرياً**، لا توصية علاجية مثبتة |
| توفر الدواء بالصيدليات | البوابة النشطة placeholder، ونسخ قديمة تحوي أمثلة | **خارطة توسع**؛ لا مخزون حي متصل بالصيدليات حالياً |
| الأسئلة والأجوبة | أمثلة مطابقة في نسخة قديمة | **خارطة توسع**، لا خدمة طبية حية مثبتة |
| حماية البيانات وإدارة الصلاحيات | تخزين JSON محلي واختيار دور في الجلسة؛ ليست منظومة مؤسسية إنتاجية | الحماية المؤسسية والتحكم بالوصول والتكاملات من متطلبات المرحلة القادمة |
| الفئات | مرضى، وصيدليات وعيادات ومستشفيات | مسارا B2C وB2B كفئات مستهدفة؛ لا عقود أو أعداد عملاء أو إيرادات مختلقة |

الموجز التسويقي تضمن «آمن» و«بحث لحظي». بُني السرد النهائي على حالة الكود، وفصل ما هو قائم عما هو مخطط له.
لم تُخترع أرقام انتشار أو سوق أو إيرادات أو أثر سريري أو مبلغ استثمار.

## النسختان

| البند | V1 | V2 |
|---|---|---|
| المقاس والإيقاع | 1920×1080، 60fps، 101ث/6060 إطاراً | نفس المواصفات |
| الهوية | أبيض/أزرق/سماوي شفائي، Kufam للنص التحريري | نفس هوية المنتج؛ لا خاتمة تقني مفروضة على المستثمرين |
| السرد | مشكلة الورق ← السجل الموحد ← QR ← الطبيب ← أدوات الدواء ← الفئات ← الخطة والمرحلة التالية | نفس السرد والصوت؛ إعادة إخراج بصري مستقلة |
| الحركة | تكوين مهني هادئ وإطارات لقطات أصلية | هوك عربي أكبر، انتقالات فصول، نوافذ Stageshow محتفظة باستمراريتها، تبديل المحتوى وحركة كاميرا ومؤشر |
| عناصر V2 الفعلية | لا تنسب إليها أدوات النسخة الثانية | StageShow Window وMacPointer وCard وCSS tokens؛ تكييف الكاميرا والتبديل مع إطارات Remotion |
| المحتوى الأصلي | شعار ولقطات التطبيق ببيانات وهمية | نفس المحتوى الأصلي؛ بطاقة «دون تحميل تطبيق» شرح تحريري بجانب QR، وليست عنصراً جديداً من التطبيق |
| الصوت | تعليق عربي رسمي بصوت Tariq عبر ElevenLabs؛ مزج مع Foley مرخص ودون موسيقى | **نفس الصوت والمزج بالكامل**؛ لا توليد أو تسريع أو معالجة جديدة |

كان Gemini Voice مسار التوليد المقصود أولاً؛ فشلت محاولاته وقت التنفيذ، فاستُخدم ElevenLabs في هذا المشروع.
هذا حل تنفيذي لشفائي، ولا يغيّر مزود الصوت الافتراضي للقناة.
Remotion `4.0.373` وReact `19.2.0`؛ تحريك الكلمات العربية كاملة دون تفكيك اتصال الحروف.
في V2 توجد تركيبة reduced-motion؛ وجودها لا يعني أنها اجتازت مراجعة سلوك مستقلة.

## الحفظ الصوتي والفحص

- بصمة WAV للمزج المحفوظ: `5a3812284abe3f49e2c4e2be57afba861767d55b529cbdd7ace68fda68a6cee6`.
- بصمة حزم AAC النهائية في النسختين: `1d69e7c197f802630dacf75cee9765061d2779fd3cea3b3d85859ba7098d3a74`؛ تطابق بتّي بحسب تقرير الإنتاج.
- كلاهما H.264/AAC، صوت 48kHz، ومدة 101.000ث. أعلى عينة صوت مقاسة −4.97dBFS، وصفر عينات مقصوصة.
- مقارنة المصدر بثلاث نقاط: 3.98 و31.337 و77ث؛ إزاحة 0ms في النقاط الثلاث. هذه عينات تحقق، وليست ادعاء محاذاة كل كلمة من البداية للنهاية.
- أصلح V1 تداخل عنوان في مشهد الورق وتأخير AAC قبل التسليم.
- أصلح V2 بطاقات placeholder إلى تفاصيل تجريبية مفيدة، واستغل فراغ نافذة QR ببطاقة تفسير مستقلة.
- مراجعة V2 شملت 43 إطاراً مستخرجاً من MP4 النهائي، البداية، تبديل التبويبات وQR وأدوات الدواء، والنهاية حتى 100.983ث.
- لم تُنفّذ مشاهدة آنية متصلة لكل ثانية أو بوابة StageShow الحية `film.mjs --gate`. الفحص كان لإخراج Remotion؛ لا ندّعي اجتياز بوابة محرك آخر.

تقرير فني جيد أو طلب الرفع لا يساوي إعجاب المستخدم. لا يوجد ثناء صريح موثق على تصميم V1 أو V2 بعد التسليم.

## إعادة العمل على المشروع

يتطلب المصدر Node.js 22+ وFFmpeg وChromium متوافقاً. من داخل مجلد النسخة:

```bash
npm ci
npm run studio
npm run render
```

يمكن تحديد المتصفح عبر `REMOTION_BROWSER_EXECUTABLE`. اتبع README كل نسخة لإعادة التقاط واجهات المشروع أو تعديل المزج.
عند تعديل الصورة فقط، احفظ الصوت كما هو. عند تغيير النص المنطوق، يلزم صوت وتوقيت جديدان موثقان.
الخطان Kufam وInter برخص OFL، وStageShow برخص MIT، وFoley الأصلي CC0 مع بيانات مصدره داخل الحزم.
لا توزع حزمة مكونات React Bits مستقلة أو تنسب أيقونات أو صور المنتج إلى القناة.
