# Docker — واجهة بيضاء واسعة

مثال جديد بأسلوب واجهة منتج عريضة: تصميم أبيض متجاوب، بطاقات عريضة تتحرك بسلاسة، شعارات Docker الأصلية، وأيقونات SVG من مكتبة المهارة. السرد يمر على image وcontainer وCompose وvolumes وregistry وتكامل MCP Toolkit.

- **الفيديو:** 1920×1080، 30 fps، 16:9، نحو 2:03.
- **الحركة:** نصوص وأيقونات وبطاقات متحركة، مع إبراز الكلمات حسب الصوت.
- **التنفيذ:** Remotion مع SVG وDOM ثنائي الأبعاد؛ لا يعتمد على WebGL.
