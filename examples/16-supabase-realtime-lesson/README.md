# Supabase Realtime — تطبيق مهام جماعي

[▶ تشغيل الفيديو مباشرة](https://github.com/Hadani0mar/skill/raw/refs/heads/main/examples/16-supabase-realtime-lesson/supabase-realtime-lesson.mp4)

76 ثانية • 1080×1920 • 30fps • نص عربي متحرك ومؤثرات صوتية، بدون تعليق صوتي.

شرح Realtime وأدواته، ثم محاكاة قائمة مهام مشتركة: عضو ينهي مهمة، وتظهر علامتها عند بقية الفريق. يتناول تجهيز جدول المهام وصلاحيات RLS وتفعيل Postgres Changes والاشتراك بالتغييرات وإعادة جلب الحالة بعد رجوع الاتصال.

التصميم مستوحى من الصور المرفقة: خلفية فاتحة، نص أزرق وأسود، تحديد سماوي، حركات نصية وقوائم. الشعار والأيقونات من m0usasvg، ومؤثرات React Bits مستخدمة داخل الفيديو النهائي.

الأسماء والمهام والواجهة بيانات تجريبية؛ الفيديو محاكاة تعليمية وليس اتصالاً حياً بمشروع Supabase. مقتطف الاشتراك توضيحي. الفلتر ليس بديلاً عن صلاحيات أعضاء الفريق.

المستودع خاص: رابط التشغيل يحتاج حساب GitHub لديه صلاحية الوصول.
